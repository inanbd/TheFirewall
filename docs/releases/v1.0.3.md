TheFirewall **1.0.3** shows the country and flag of every address and lets you block a whole country from the lists. It also adds **Ban forever** and fixes wrong or doubled rows in the activity feed and the empty "Attacks by country" panel.

## New

- **Country column with flags.** Live activity, Banned and Watching show each address's country and flag. Flags also appear on the dashboard, the Countries page and the address details window.
- **Block a whole country from the lists.** Hover over (or select) a row and click the block button in its Country cell. You can also use **Block country** on the Banned and Watching toolbars, the right-click menus, or the address details window. TheFirewall asks first and works with any country blocking mode:
  - if country blocking is off, it is turned on for that country only;
  - if you block selected countries, the country is added to the list;
  - if you allow only selected countries, the country is removed from the allowed list (it refuses to remove the last one).

  Whitelisted addresses and your local network are never blocked.
- **Ban forever.** Available on the Banned list (turns temporary bans permanent), the Watching list, the activity right-click menu, address details and the **Ban an address** dialog.
- **Search activity by country name**, for example "China", as well as by code.

## Fixes

- **Failed Remote Desktop logons no longer show as "Signed in".** All monitors of one event log used to share a subscription, so failed logons (event 4625) also reached the RDP sign-in monitor. Each monitor now has its own subscription and checks the event id and logon type itself. CI now triggers real failed Windows logons and fails if any is reported as a sign-in.
- **One row per sign-in attempt.**
  - Windows reports one failed RDP attempt in two logs. These now count once and show as one row.
  - The failed steps Windows logs while a Remote Desktop client negotiates credentials just before a successful sign-in are no longer shown or counted towards a ban.
  - Duplicate "Signed in" events show once.
- **"Attacks by country" stayed empty** because the downloaded country database was never loaded. It now loads, and countries are filled in for activity and addresses recorded earlier.

## Upgrading

- **Installer:** run `TheFirewall-1.0.3-x64.msi`; it upgrades 1.0.x in place. Settings, bans and history are kept.
- **Portable:**
  1. Close the tray icon (right-click → **Exit (protection keeps running)**).
  2. Run `TheFirewall.Service.exe stop` as administrator from your current folder, so its files can be replaced.
  3. Extract the new zip over that folder and open `TheFirewall.exe`. It starts the service again.

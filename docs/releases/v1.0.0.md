The first release of **TheFirewall**: brute-force protection for Windows. A background service watches your logs for failed sign-ins and bans the attacking IP addresses with Windows Defender Firewall. A Fluent control panel and tray icon show what it is doing.

## Download

| File | What it is |
| --- | --- |
| `TheFirewall-1.0.0-x64.msi` | **Installer (recommended).** Installs the service and the app and adds a Start menu shortcut. It also shows the tray icon at sign-in. |
| `TheFirewall-1.0.0-x64-portable.zip` | The same files without an installer. Run `TheFirewall.Service.exe install` from an elevated prompt. |
| `SHA256SUMS.txt` | Checksums for both files. |

**Requirements:** Windows 10 1809+ or Windows Server 2019+ (x64), with Windows Defender Firewall turned on. No separate .NET install is needed because the runtime is included.

The installer is not code-signed yet. Windows SmartScreen may warn about it; choose **More info → Run anyway**. You can compare the file's checksum with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\TheFirewall-1.0.0-x64.msi -Algorithm SHA256
```

## Highlights

- **Bans attackers automatically** after 5 failed logins. Repeat offenders get longer bans (1 day → 7 days → 30 days); everything is configurable.
- **Detects everything IPBan detects on Windows:** RDP / Windows logon, OpenSSH, SQL Server, MySQL / MariaDB, PostgreSQL, phpMyAdmin, Exchange, SmarterMail, MailEnable, RD Web Access, Apache / Tomcat, VNC, RRAS / VPN and VisualSVN. IIS FTP and hMailServer are also supported.
- **Custom login monitors** for any event log or text log, with a built-in tester.
- **Custom firewall rules**, a whitelist (never ban) and a blacklist (always block).
- **Country blocking:** block chosen countries, or allow only the countries you choose.
- **Optional threat feeds**, off by default.
- **Live activity feed and dashboard** with charts, top attacking countries and the user names attackers tried.
- **Tray icon** whose colour shows the protection status, with notifications for bans and quick pause/resume.
- **Backups:** import and export settings and bans, export to CSV and run your own scripts on events.

## Before you deploy

- Add the addresses you connect from (office, home, VPN, monitoring) to the **whitelist** so a few typos never lock you out. Local network addresses are never banned by default.
- Try it on a non-production machine first, and watch **Live activity** for a while before relying on it.
- Locked out anyway? From the console, run `TheFirewall.Service.exe remove-rules` to delete every rule TheFirewall created.

Uninstalling removes the service, the tray sign-in task and all of TheFirewall's firewall rules.
